`snapshots/<YYYY-MM-DD>/catalog-observation.json` once a live parity run is
actually performed and reviewed. No observation exists yet; this folder is
empty of results on purpose. See the live validation steps in the
[operations guide](../../OPERATIONS.md) and the runbook entry in the
